# DPC diagnostic

This cartridge is a visible PASS/FAIL test for Atari DPC cartridges.  DPC is
modeled as two ordinary 4K F8 program banks plus a 2K data-only display bank
and a 255-byte data-only Poly8 bank.

The diagnostic executes the complete 2x2 ordered call matrix across the two F8
program banks plus one nested cross-bank return. Same-bank calls are ordinary
JSRs; cross-bank calls use the descriptor ABI documented in
[`../../../BANKSWITCHING.md`](../../../BANKSWITCHING.md). DPC's mapper-local
trampoline is byte-identical to the F8 descriptor implementation because its
program-bank selector geometry is identical; descriptors are `$F8/$F9`. The
diagnostic also checks all 2048 display bytes through DPC fetcher 0 with an
order-sensitive checksum and wrap test, and checks a complete 255-state RNG
cycle after resetting the DPC LFSR.

`make play` forces Stella's DPC mapper.
The visible result uses the same presentation as the other bankswitching diagnostics: lowercase **pass** / uppercase **FAIL** in the 8x16 Big font, with the compact `DPC` mapper label immediately below it. The checked-in `status_font.c26` and `cart_type_font.c26` subsets are regenerated by `make fonts`; normal builds do not require Perl.
