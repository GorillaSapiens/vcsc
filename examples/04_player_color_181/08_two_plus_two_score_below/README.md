# Left/right two-plus-two score below gameplay

The interactive cartridge draws the 11-line independently positioned left/right two-plus-two score after the
181-line `player_color_181` gameplay renderer. The pair uses the measured component
handoff and consumes exactly 192 visible scanlines.
