# Colour sections, score below

Run `make`, then `make play` (Stella). This builds an **8K F8** cartridge.

Controls, score editing, section configuration and memory limits are identical
to the [score-above example](../score_above/README.md). Only the visible component
order differs: gameplay first, the 11-line score below it.
