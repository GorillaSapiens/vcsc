`player_color_192_animated_sprites.c26` contains one-bit silhouettes extracted
from source sprites 1 through 120. Source color 0 is treated as transparent and
every nonzero source color as opaque; no PICO-8 palette data is retained. These
silhouettes are adapted artwork and remain subject to the original CC BY-NC-SA
