# Full 192-line display

All examples in this layout give `player_color_192` the complete 192-line
visible field. They use the same playfield, player graphics, player-color rows,
and Ball scene while progressively adding motion.

| No. | Example | Motion |
|---:|---|---|
| 01 | [`static`](01_static/) | None |
| 02 | [`dynamic_x`](02_dynamic_x/) | Asynchronous horizontal P0, P1, and Ball motion |
| 03 | [`dynamic_xy`](03_dynamic_xy/) | Asynchronous horizontal and vertical P0, P1, and Ball motion |
