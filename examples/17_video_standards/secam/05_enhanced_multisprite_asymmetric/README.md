# Native SECAM 228-line enhanced asymmetric multisprite

This interactive cartridge runs the asymmetric six-sprite enhanced multisprite
renderer across all 228 visible SECAM scanlines (114 logical two-line bands).
It uses the renderer's native `lines:=228` profile; no visible border padding is inserted.

Use Select to choose a logical sprite and the left joystick to move it. Reset
restores the initial six-sprite scene.
