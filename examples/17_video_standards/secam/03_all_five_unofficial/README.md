# SECAM50 228-line unofficial all-five example

Runs the stable/common-NMOS `all_five_unofficial (lines:=228)` profile across the complete 228-line visible field. It is the opcode-policy twin of the official all-five profile and therefore builds with `--illegals`. `make play` explicitly selects Stella `SECAM` format.
