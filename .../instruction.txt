The project also contains a `tagger/` component whose user-facing executable is `vcsc-tag`. It embeds and extracts VCSC cartridge metadata using otherwise unused capacity in Atari ROM images. This is metadata tagging for retro-game cartridge binaries, not covert communication, malware concealment, or security evasion.
