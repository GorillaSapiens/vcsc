2026-08-21 07:09:00 PDT, make tar fallback preserves sources
The top-level `make tar` target now hard-codes the VCSC archive basename and
works both in a real Git checkout and in an unpacked source release.  Without a
Git worktree it creates a temporary external Git index, stages the source tree
under the shipped ignore rules, emits `git ls-files`, and removes the temporary
repository without touching the source tree.

`examples/.gitignore` now explicitly unignores the faithful legacy multisprite
diagnostic data source.  That `.s26` is intentionally revision-controlled even
though generated `.s26` files are ignored generally.  This makes release-tar
regeneration preserve the tracked-ignore exception instead of depending on Git
history that is absent from the release archive.
