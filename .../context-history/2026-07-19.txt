2026-07-19 00:00:00 PDT, make VCS 4K layout the driver default

  now requires `-T FILE`, `--script=FILE`, or a positional `.cfg` and emits a
  focused diagnostic when no script is supplied.
* Extended `n65cc` path discovery to locate `libraries/vcs/vcs_4k.cfg` in the
  source tree or `share/vcs/vcs_4k.cfg` beside an installed toolchain. The
  driver always passes an explicit script, using the user-supplied `-T` when
  present and the bundled VCS 4K layout otherwise.
* Added `test/generic_6502.cfg` as an explicit test-only layout for retained
  generic compiler/linker/simulator regressions. The production toolchain no
  longer preserves a generic target by accident.
* Added regressions for the driver's default VCS script and the linker's
  script-required error. Updated both cartridge regressions and both example
  Makefiles to omit `-T`, proving the default path in real 4096-byte builds.
* Updated staged installation to build the solid-color cartridge through the
  installed driver and installed `share/vcs/vcs_4k.cfg`.
* Passed 227/227 compile tests, 101/101 end-to-end/generic tests, both exact

2026-07-19 07:11:04 PDT, add packed-BCD integer family
* Added `$bcd` as an unsigned one-, two-, or three-byte scalar type flag and
  defined stock `bcd8_t`, `bcd16_t`, and `bcd24_t` types for two-, four-, and
  six-digit packed decimal values. The three-byte type is a deliberate
  Atari-specific decimal exception, not restored generic 24-bit binary math.
* Added one numeric literal encoder for static initializers, automatic
  initializers, runtime assignments, aggregate/array elements, typed constants,
  and fixed arguments. Decimal `42`, hexadecimal `0x2a`, octal `052`, and binary
  `0b101010` all become packed byte `$42`; multibyte values use least-significant
  decimal pairs first. Range diagnostics enforce 0..99, 0..9999, and 0..999999.
* Added tightly scoped decimal-mode lowering for BCD `ADC`/`SBC` chains,
  including `+`, `-`, `+=`, `-=`, and valued/discarded `++`/`--`. Generated code
  executes `CLD` immediately after each operation; an execution regression
  verifies the following ordinary binary addition remains binary.
* Added BCD-aware assignment, widening/truncation, comparisons, truth tests,
  switch lowering, parameters, `bcd8_t`/`bcd16_t` returns, and ABI fingerprints.
  Rejected signed/pointer/invalid-width BCD declarations, BCD bitfields,
  multiply/divide/remainder, bitwise operations, shifts, unary minus, runtime
  BCD/binary representation changes, and `bcd24_t` returns.
* Fixed the inherited direct-copy assignment shortcut so `old := value++` and
  its decrement/prefix variants preserve the source side effect; added an
  ordinary-binary end-to-end regression in addition to BCD coverage.
* Added 27 runnable BCD-specific tests plus the generic inc/dec assignment
  regression, and extended the native VCS header smoke test to exercise the
  stock BCD declaration. Passed 250/250 compile tests, 106/106 end-to-end and
  generic tests, the staged install check, both exact 4096-byte cartridge
  regressions, and an installed-toolchain BCD cartridge smoke build.
* Documented representation, literal semantics, supported operations, decimal
  mode invariants, conversion boundaries, and the A:X return limitation. No
  files were removed; remove.txt remains at 487 cumulative paths, and the
  retained legacy BASIC trees were untouched.

2026-07-19 07:40:01 PDT, preserve valued increment/decrement side effects in all shortcut paths
* Confirmed the ordinary assignment bug fixed during BCD work was not the only
  inherited variant. Compact one-byte comparisons could compare `value++`

  absolute ref and the optimized one-byte array-index path could do the same.

* Passed 251/251 compile tests, 107/107 end-to-end/generic tests, and the staged
  installation check. No files were removed; remove.txt remains at 487 unique
  cumulative paths, and the retained legacy BASIC trees were untouched.

2026-07-19 11:55:11 PDT, replace register returns with callee-owned memory
* Replaced the A:X scalar/pointer return ABI with exact-sized hidden
  `function$__return` zero-page objects owned by each value-returning function.
  One- and two-byte binary values, pointers, and one-, two-, or three-byte BCD
  values now use the same memory-backed mechanism.
* Changed value epilogues to plain `RTS`; callers restore the frame pointer
  normally and consume the callee return object directly instead of preserving,
  spilling, or reconstructing A:X. Ignored results do not import or copy the
  hidden object.
* Exported non-static return objects and imported them only when an external
  call's value is consumed, so separately compiled functions follow the same
  ABI without creating unnecessary cross-object references. Static functions
  retain private return objects.
* Changed ABI metadata from `return_ax` to `return_memory` and updated compiler,
  runtime, and ABI documentation. Added same-translation-unit and
  cross-translation-unit `bcd24_t` return execution tests, plus code-generation
  tests for static, external, ignored, one-byte, and two-byte return cases.
* Added scalar-width roadmap task 18 before the retained legacy BASIC conversion
  inventory: generalize one- through four-byte scalar machinery, then add
  `int24_t`/`uint24_t`, `int32_t`/`uint32_t`, and `bcd32_t`. Marked memory returns
  complete as task 18a and left legacy renderer conversion as task 19.
* Updated the main README to identify VCSC as the Atari-focused child of the N
  parent project and link `https://github.com/GorillaSapiens/n`.
* Passed 254/254 compile tests, 110/110 end-to-end/generic tests, both exact
  4096-byte cartridge regressions, the staged installation check, and an
  installed-toolchain 4096-byte cartridge using a returned `bcd24_t`. Added six
  superseded test paths to `remove.txt`, which now contains 867 unique cumulative
  paths. The retained legacy BASIC trees were untouched.

2026-07-19 12:20:05 PDT, remove inherited runtime frame pointer
* Replaced runtime scratch-base redirection with a compile-time active-lease
  stack. Scratch helpers now address the selected linker-resolved
  `__vcsc_scratch_N` symbol directly and prepare `ptr0`/`ptr1` only for dynamic
  or offsets beyond the direct indexed range.
* Removed `_vcsc_fp` from the zero-page runtime workspace, startup initialization,
  assembler include aliases, compiler reserved names, peephole scratch tracking,
  and ordinary call lowering. Deleted `libraries/runtime/asm/fp2ptr.asm` and the
  generated helper family.
* Removed frame-pointer save/restore around argument evaluation and JSR. Ordinary
  generated calls now use only the hardware stack's two-byte return address, so
  call-graph RAM reservation changed from four bytes to two bytes per linked
  source call depth. Images with runtime initializer functions add one fixed
  two-byte allowance for startup's preserved init-table cursor.
* Reclaimed two bytes of RIOT RAM from the stock runtime workspace, now 16 bytes.
  Updated VCS map expectations: the two-deep 4K example reserves $FC-$FF and the
  three-deep Ode example reserves $FA-$FF.
* Renamed compiler helper APIs and stale comments from fp-relative terminology to
  direct scratch terminology. The ordinary source identifier `fp` is legal again.
* Added `fp_removed.test`, which compiles an `fp` variable, checks direct static
  scratch addressing and push-free calls, scans runtime/linker sources, and
  verifies the rebuilt archive contains no fp helper.
* Passed 254/254 compile tests and 112/112 end-to-end/generic tests. The staged
  installation check and both exact 4096-byte cartridge regressions passed.
  Added two removed paths to `remove.txt`, now 869 unique cumulative paths. The
  retained legacy BASIC trees were unchanged.
