2026-08-29 18:26:09 PDT, complete FE/SCABS public bankswitching support
Completed bankswitching roadmap Item 42. Added public vcs_8k_fe.c26/vcs_8k_fe.cfg
and examples/09_bankswitching/14_fe. FE uses its real delayed $01FE bus-latch
contract rather than an invented hotspot: any mirrored $01FE access arms the
selector, and the following bus cycle's data chooses the physical bank. With
SP=$FF this permits the released-cart top-level JSR/RTS idiom: JSR's low return
byte push hits $01FE, the following target-high fetch selects bank 1, RTS later
reads $01FE, and the following caller-high stack byte restores bank 0.

The compiler already communicates the selected mapper generically through C26
cartridge/topology metadata. vcsc-ld reconstructs that topology from O26
metadata and applies the FE-only lowering/restrictions only when the cartridge
signature/topology identifies FE. Function ownership comes independently from
assembler-preserved .proc layout names, so the FE linker rule can require a
cross-bank JSR relocation to be owned by main without imposing that rule on
other mappers.

Automatic FE ROM stays in startup bank 0; bank 1 requires explicit placement.
The linker permits only direct cross-bank JSRs owned by main and rejects nested
cross-bank calls plus cross-bank JMP, branch, and ROM-data references. This is
currently a conservative structural rule, not an instruction-level proof that
SP=$FF at every such JSR; the startup/simple-call convention supplies that
precondition. The FE diagnostic deliberately uses the simple startup because
stack-heavy generic startup can itself touch $01FE. The big-wide score component
therefore gained an initial_color parameter whose default remains $0E; the FE
example requests zero/BSS startup and sets its color explicitly afterward.

vcsc-sim models the one-cycle-delayed selector and test/vcs_fe.pl contains a
poisoned fixture that fails if $01FE switches immediately. FE disassembly is
high-confidence and byte-exact round-trip. Stella 7.0 renders and grades the
public PASS/FE diagnostic successfully. Recursive example builds and the general
C26 cartridge-profile regression include FE.
