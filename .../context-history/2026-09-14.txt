2026-09-14 09:10:15 PDT, correct split-RAM bus semantics
Audited A5/A7 and detached speculative memory semantics after repeated mapper
regression whack-a-mole. The prior split-RAM model was electrically wrong:
writes to a read alias are legal ignored cycles, while reads from a write alias
return an unpredictable read-from-write-port value and overwrite the backing RAM
byte. RMW is therefore legal on either alias and is now diagnostic/neutral--it
neither vetoes nor proves Superchip, FA/FA2, CV, WD/WDSW, E7, or 3E. Only pure
direction-correct split-RAM accesses may contribute positive mapper evidence.

Separated A5 bus legality from detached-island usefulness. Writes to mapped ROM
remain legal for mapper viability but are not meaningful speculative write sinks;
this fixes the plain-F8 speculative Superchip-store regression without restoring
the false ROM-write contradiction. Added a direct established ROM-RMW legality
regression instead of using speculative-island promotion as a proxy for bus
validity.

Cartridge-RAM provenance now models the hardware side effect: an exact read from
a write alias destroys the prior backing-byte source; unknown absolute indexing
enumerates all 256 possible aliases, and unresolved indirect reads conservatively
drop split-RAM provenance. Writes to read aliases preserve the old backing source.
New FA regressions pin exact RWP destruction, unknown-index destruction, and
ignored read-alias writes.

Removed obsolete split-RAM-RMW hard-failure contracts and renamed stale fixtures.
The complete current generated disassembler corpus round-trips 206/206 byte-exact,
the full assertion tail reports `vcsc-disas regression suite ok`, and the
hardening suite passes. Also corrected two buried JANE/F6 hypothesis-count checks
from 6 to 7 after CM became a legitimate 16K hypothesis.
