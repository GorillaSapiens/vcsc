Important implementation lessons:
* A fixed page of small JMP trampolines lets dispatch fetch only one ROM byte per
  pair, while keeping a fixed high pointer byte and runtime graphics pointers.
* The indexed dispatch table itself MUST be page-contained (not only trampolines),
  otherwise indexed read page crossings add a cycle and silently lengthen frames.
* Inline normal P1 clipping with a short local branch materially improves final
  bank packing; moving all clipping paths out to distant cold prefixes did not.
* ENABL is staged through VDELBL/GRP1: boundaries can install next-row Ball while
  computing it, freeing later slots to match the ordinary COLUP1 handoff.
* An inactive P1 path cannot freely move its row-zero colour write: extended/right
  edge copies can still expose previous graphics at that point in the scanline.
* Conditional compilation cannot bisect an instantiate argument list. Select a
  quoted component-path alias before the instantiate statement instead.
