VCSC MAIN ROADMAP
=================

Purpose
-------
This file preserves the detailed project roadmap formerly embedded in
`.../context.txt`. The compact context file states the active workstream and
next action; this file owns the detailed main-roadmap checklist and acceptance
criteria. `.../bankswitching.txt` separately owns the detailed bankswitching
sub-roadmap.

Do not duplicate completed implementation history here. Record completed work
in the appropriate daily file under `.../context-history/`, then update the
checkboxes and current-state wording here.
