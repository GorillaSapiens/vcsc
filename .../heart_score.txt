HEART SCORE COMPONENT
=====================

Stable state
------------
`libraries/vcs/heart_score_component.c26` is the maintained 0..11 full-heart
component. Thomas Jentzsch's supplied 11-Invaders binary remains the hardware
oracle: the component copies a 45-byte renderer to RIOT RAM, patches enabled
logical RESP slots versus equal-cycle reads, and uses centered setup index 5.

Eleven hearts define the fixed footprint. Smaller values are exact left-prefixes
at the same positions; values above 11 clamp to 11. The singleton P0 path needs
one extra VBLANK HMOVE correction, and P0 must be zero-motion while a following
P1 singleton setup HMOVE runs. Do not remove either correction as an apparent
cleanup: Stella 7.0 all-count coverage locks scores 0..11 pixel-for-pixel.

The component consumes seven visible scanlines and 58 bytes of instance RIOT
RAM. The public 2K example is `examples/01_basic/14_heart_score/`.

Optional future work
--------------------
A final half-heart may be added as a separate enhancement, but it must preserve
the certified 0..11 full-heart footprint and timing.
