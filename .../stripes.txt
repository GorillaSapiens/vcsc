VCSC RENDERER / STRIPES ROADMAP
================================

Goal
----
Consolidate gameplay renderers before item 57 stripes. Components live under
`libraries/vcs/components/`. `all_five`, `player_color`, and both former
`all_five_player_color_*` profiles are unified behind compile-time `lines`,
missiles, and player colors; both unofficial and both `standard_4k_ntsc*`
predecessors are retired after preserving useful coverage. Add `stripes` next.
`multisprite` and `enhanced_multisprite_asymmetric` remain distinct.

Stripe ABI
----------
Add `parameter stripes := 0;`; zero preserves the old path with no arrays.
`stripes:=N` requires `game_playfield_colors[N*2]` and
`game_playfield_data[N*6]` (`TEMPLATE_playfield_colors/data`). Store COLUPF/COLUBK
then left/right PF0/PF1/PF2; stripe i owns
`floor(i*L/N)..floor((i+1)*L/N)-1`. Preserve raster/timing/handoffs/resources/write
phases; no runtime division or per-line feature test.

Renderer inventory
------------------
Modern schedules: draw entry 3, return 0, terminal WSYNC, VBLANK <=1800.
Full-height 228/192: no entry HMOVE/successor, overscan <=66. Score-composable
181/170: one entry HMOVE + successor; overscan <=58 all-five, <=40 player-color.

* `all_five`: 5 objects, solid P0/P1, 23 public bytes; lines 228/192/181/170,
  playfield 60/48/44/40, module RAM 83/71/67/67.
* `player_color` specialization in `all_five`: P0/P1/BL + 8-row colors,
  13 public; same lines/playfields, module RAM 23/23/24/24.
* `all_five` combined 192 specialization (`missiles:=1, player_colors:=1`):
  5 objects + row colors, 21+62=83 RAM, 48-byte mask + 14-byte row cache;
  full-height schedule.
* `all_five` combined 181 specialization (`missiles:=1, player_colors:=1`):
  5 objects + row colors, 21+67=88 RAM, 46-byte mask + 21-byte row cache;
  all-five score-composable schedule.
Preserve exact frame/score checks, `vcs_playfield_phase.cpp`,
`vcs_standard_objects.cpp`, `vcs_all_five_composition.cpp`, the exhaustive
`vcs_all_five_pairwise` horizontal-position oracle, and pinned-palette Stella RGB
comparisons. Principal tests are the `vcs_all_five_*`, `vcs_player_color_*`, and
combined-color families. Examples live under `04_renderers/`, native 50 Hz under
`05_video_standards/`, and the all-five banked diagnostic under `07_diagnostics/`.
