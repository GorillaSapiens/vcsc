VCSC SOFTWARE-STACK INVENTORY
=============================

Purpose
-------
This is the checked inventory for Immediate TODO step 6 in context.txt.  It
records every compiler site that still emits a runtime `_pushN` allocation and
classifies why that storage exists.  It is a snapshot of the transitional ABI,
not an endorsement of the software stack.

Snapshot
--------
Input archive:

    vcsc.20260716_215237.tar.gz

Compiler emission totals:

    10  `jsr _pushN` allocation sites
    22  `jsr _popN` emissions

The larger pop count is expected: most allocation sites have normal cleanup and
one or more error-path cleanups.

Named automatic locals
----------------------
There are no remaining `_pushN` sites whose purpose is to allocate ordinary
named automatic locals.  Named automatic locals and the hidden `$$` return
object already use fixed-address symbols.

Do not confuse the compiler's host-side `ctx_push()` bookkeeping function with
the target runtime helper `_pushN`; they are unrelated despite the unfortunate
name collision.

Non-emitting compiler consumers
-------------------------------
Helpers that manipulate `ctx->locals` and `(fp),y` scratch without emitting
`_pushN` own no persistent function frame. Their temporary bytes belong to an
enclosing expression, statement, initializer, or lvalue allocation.


Runtime and generated-library dependencies
------------------------------------------
The target stack mechanism itself lives in:

    libraries/nlib/asm/stack.asm       `_pushN` and `_popN`
    libraries/nlib/nlib_zeropage.s     `_nl_sp` and `_nl_fp`
    libraries/nlib/nlib.inc            `sp` and `fp` aliases
    libraries/nlib/nrt0.s              startup initialization

Large additional dependency families are already outside the final language:

* `libraries/float/asm/*` uses `_pushN`/`_popN` extensively.
* `libraries/nlib/genasm.pl`, `gen_weakops.pl`, and `asm/weakops.asm` generate
  wide/general arithmetic helpers around the old stack ABI.

Disposition and implementation order
------------------------------------

A. Remove first, because the feature itself is unwanted:

   * operator overloading and weak built-in operator calls;
   * float, wide-integer, and arbitrary-endian branches;
   * bit-field or aggregate-only scratch if those features are later rejected.

B. Replace for the retained language:

   * scalar truth/comparison/binary/shift/cast scratch;
   * pointer arithmetic and indexing scratch;
   * simple/compound assignment scratch;
   * switch-expression scratch;
   * scalar runtime initializer and return-object scratch.

C. Replace conditionally, after language-surface decisions:

   * aggregate/braced initializer scratch;
   * bit-field scratch;
   * runtime global initializers.

Completed expression-scratch slices
-----------------------------------
Truth-value evaluation, discarded expression results, simple assignment
conversion into fixed-symbol destinations, indirect/absolute/bit-field simple
assignment, two-operand comparisons, pointer subtraction, scalar/pointer
addition and subtraction, shifts, bitwise operations, multiplication, division,
remainder, casts, local/global absolute-reference conversion, built-in
increment/decrement, built-in compound assignment, switch expressions, runtime
local/return-object initialization, and local absolute-reference initialization
now use private fixed BSS scratch. New symbols in this revision include
`__n65_lvalueassigntmp_N`, `__n65_compoundtmp_N`, `__n65_switchtmp_N`,
`__n65_inittmp_N`, and `__n65_absinittmp_N`.

The compiler temporarily redirects `fp` to each symbol, tracks nested scratch
high-water, restores the caller frame through the 6502 hardware stack, and
copies converted result bytes into the caller destination. These paths no
longer emit `_pushN` or `_popN`. Scratch is per evaluation site and is not
overlaid yet.

Completed call-ABI removal slices
---------------------------------
Ordinary direct calls use fixed BSS scratch named `__n65_calltmp_N`. Arguments
are copied into callee-owned parameter symbols, and A:X is captured there only
when conversion into a memory-backed destination is required.

Variadic syntax, call lowering, hidden callee metadata, compiler builtins,
`libraries/nlib/stdarg.n`, and `libraries/nlib/sprintf.n` have been removed.
The lexer rejects `...`. The obsolete direct-call software-stack fallback and
persistent per-function software frame were deleted.

Function pointers and indirect calls have also been removed completely. The
compiler rejects function-pointer declarators and function designators used as
values, and the `_callptr0` runtime trampoline is gone. `compile_call.c` no
longer emits `_pushN` or `_popN`.

Recommended next slice
----------------------
Replace pointer/index lvalue scratch next, including the saved-pointer areas used
by ordinary indexing. Then replace or reject braced-assignment initializer
scratch. Operator-overload-only emitters should be deleted with operator
overloading rather than converted.
